Phase 3 — Scope Analysis & Layer Organization
====================================================

This phase identifies relevant functions for incremental analysis, builds
dependency-ordered top-down layers from call graphs, and creates batched prompt
files for parallel specification generation.

Key Types and Structs
---------------------

Scope Functions (src/scope.py):
  rank_functions_in_file(filepath, src_path, issue, signals, top_k, llm_client, ...)
  Returns list of ranked function dicts, sorted by descending score:
  [
    {"file": str,           # source file path
     "name": str,           # function name (deduped, matches extracted file name)
     "lineno": int,         # 1-based start line
     "end_lineno": int,     # 1-based end line
     "score": float,        # relevance score (computed via heuristic + enrichments)
     "reason": "heuristic"|"llm"|"heuristic_pad"
    }
  ]

  Signal weights (float constants):
    W_TRACEBACK       = 10.0   # "in func_name" traceback lines
    W_BACKTICK_NAME   =  5.0   # function name in backtick spans
    W_BACKTICK_BODY   =  2.0   # backtick identifiers in function body
    W_DOTTED_REF      = 15.0   # Class.method explicit dotted references
    W_PLAIN_NAME      =  3.0   # CamelCase/snake_case in prose
    W_NAME_ALL_WORDS  =  1.5   # name-parts ∩ prose words (≥5 chars)
    W_FUZZY_NAME      =  1.4   # typo-tolerant name matching (≥75% similarity, ≥5 chars)
    W_EXCEPTION_MATCH =  4.0   # exception type mentioned in issue found in body
    W_BODY_WORDS      =  1.0   # body-word overlap / √(body_lines)

  Call-graph propagation (per-file):
    CALLEE_INHERIT = 0.30   # callee gets 30% of caller's score
    CALLER_INHERIT = 0.20   # caller gets 20% of callee's score

  Class-scope narrowing (Python only):
    W_CLASS_NAME_MATCH   = 6.0
    W_CLASS_DOC_MATCH    = 2.0
    CLASS_METHOD_INHERIT = 0.40  # method gets 40% of class score
    CLASS_BOOST_CAP      = 8.0   # hard cap on per-method class bonus

  LLM re-ranking triggers (configurable):
    - File has ≥ SCOPE_LLM_TRIGGER_FUNCS deduped functions (default 5), OR
    - Top heuristic score < SCOPE_LLM_CONFIDENCE_THRESHOLD (default 8.0)

  Issue signals (per developer intent text):
  {
    "traceback_funcs": set[str],    # T1: function names from tracebacks
    "backtick_idents": set[str],    # T2: identifiers in backticks/blocks
    "dotted_refs":     set[str],    # T3: method names from Class.method refs
    "dotted_classes":  set[str],    # T3: class names from Class.method refs
    "plain_idents":    set[str],    # T4: CamelCase/snake_case in prose
    "exception_types": set[str],    # T5: exception type names
    "all_words":       set[str],    # T6: all alphabetic words ≥4 chars (non-stop-words)
  }

Topdown Layer JSON (phase_NN_topdown_layers.json):
  {
    "phase": int,
    "phase_name": string,
    "total_functions": int,
    "total_layers": int,
    "layers": [
      {
        "layer": int,              # 0-indexed layer number
        "cycle_resolution": bool?, # present=true if this layer resolves an SCC
        "functions": [
          {
            "name": string,        # FQN (e.g. "src::engine::loader-cpp::loadData")
            "file": string,        # relative path to extracted function file
            "unit": string,        # module name from phases.json
            "phaseN_callers": [string],  # in-phase callers (FQNs)
            "phaseN_callees": [string],  # in-phase callees (FQNs)
            "all_callees": [string],     # all-phase callees (FQNs)
            "phaseN_callee_info_names_by_caller"?: {caller_fqn: [info_names]}
          }
        ]
      }
    ]
  }

  Invariants:
  - Layers are topologically sorted: callees appear in lower-numbered layers
    than their callers.
  - SCC members (mutual recursion) are placed in the same layer.
  - all_callees may reference functions from other phases (cross-phase edges).
  - phaseN_callers and phaseN_callees are scoped to THE SAME phase only.

Batch Prompt Manifest (manifest.json):
  {
    "phase": int,
    "layers": string,            # "start-end" or single index
    "total_functions": int,
    "total_batches": int,
    "batches": [
      {
        "index": int,
        "file": string,          # prompt filename (e.g. "batch_000_layer0_extracted_b0.txt")
        "layer": int,
        "is_cycle": bool,
        "num_functions": int,    # total functions in this batch
        "num_pending": int,      # unspecced functions (may be < num_functions on resume)
        "functions": [string]    # fm_agent/-prefixed extracted function paths
      }
    ]
  }

  Batch size defaults to 2 functions per prompt file.
  On resume: num_pending < num_functions when some functions are already specced.

Function Signatures (Entry Points)
----------------------------------

src/scope.py:
  rank_functions_in_file(filepath, src_path, issue, signals, top_k=TOP_K,
                         llm_client=None, llm_model="", llm_trigger=LLM_TRIGGER_FUNCS,
                         llm_top_k=LLM_TOP_K,
                         llm_confidence_threshold=LLM_CONFIDENCE_THRESHOLD,
                         proj_dir=None) → list[dict]
  _parse_issue_signals(issue_text) → dict[str, set[str]]

src/generate_topdown_layers.py:
  generate_topdown_layers(proj_dir, phase_numbers=None, extra_call_edges=None) → [output_paths]
    Reads phases.json, collects extracted function files, builds call graph via static
    analysis (codegraph + regex fallback), computes topological layers via Kahn's algorithm
    with Tarjan SCC for cycles, writes per-phase JSON files.

  _build_call_graph(phase_files, proj_dir, global_stem_to_fqns=None, extra_call_edges=None)
    → (callees_map, callers_map, all_callees_map, file_map, module_map, edge_aliases_map)
    All maps keyed by FQN. edge_aliases_map: callee → caller → set of supplemental names.

  _compute_layers(phase_fqns, callees_map, callers_map) → list[layer_dicts]
    Kahn's algorithm for topological ordering, Tarjan SCC for cycle resolution.

src/generate_batch_prompts.py:
  main() → int  # CLI entry (python3 generate_batch_prompts.py --phase N --layers R)
  build_prompt(phase, layer_idx, is_cycle, functions, func_to_layer, all_funcs,
               work_dir, fm_agent_prefix, ext_to_lang) → string
    Constructs the full batch prompt including: earlier-layer caller specs,
    callee expectations from callers, cycle guidance, per-function file references,
    and the mandatory spec format template.

  extract_spec_block(filepath) → Optional[str]
    Returns the full [SPEC] ... [SPEC] block or None.
  extract_info_block(filepath) → Optional[str]
    Returns content between [INFO] markers or None.
  extract_callee_spec_from_info(info_block, callee_fqn, aliases) → Optional[str]
    Finds the [SPLIT]-separated entry for a callee in an info block.
