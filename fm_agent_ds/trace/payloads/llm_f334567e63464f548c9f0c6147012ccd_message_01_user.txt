streaming_reasoner(input_dir: str, output_dir: str, file_list: list[str], proj_dir: str, work_dir: str, spec_procs: list | None, already_processed: set[str], resume: bool, bug_validator_path: str | None) -> set[str]
Pre-condition: input_dir is the extracted_functions/ directory containing function files with complete spec/info sidecars. output_dir is the destination directory for verification verdict JSON files. file_list identifies the functions in scope. proj_dir is the project root. spec_procs is a list of concurrent.futures.Future objects for ongoing spec-generation tasks, or None.
Post-condition: For each function in scope whose spec/info sidecars are complete, has not yet been processed, and is not in already_processed, runs block-level Hoare-style reasoning to verify the function body against its specification. Produces a verdict JSON file under output_dir. For each MISMATCH verdict, dispatches a bug validation agent that builds and executes a probe script, producing a bug_validation/<bug_id>.md report. Returns the set of function file paths newly processed.
