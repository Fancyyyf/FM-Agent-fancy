_parse_issue_signals(developer_intent) -> dict
Pre-condition: developer_intent is a non-empty string.
Post-condition: Returns a dict containing signal dictionaries extracted from the intent text: traceback function references, backtick/code-block identifiers, dotted class-method references, plain CamelCase/snake_case names, exception type names, and body-word tokens. Each signal dictionary maps signal types to sets or lists of extracted tokens.

_llm_select_json(work_dir, prompt, stage, validator, schema_description) -> list | None
Pre-condition: prompt is a non-empty string containing the LLM selection instructions. validator is a callable that validates parsed output. schema_description specifies the expected JSON shape.
Post-condition: Returns a list of parsed JSON objects matching the expected schema when the LLM produces valid output. Returns None when the LLM call fails, times out, or produces output that does not parse or validate against the expected schema.

rank_functions_in_file(filepath, src_path, issue, signals, proj_dir) -> list[dict]
Pre-condition: filepath is a source file path relative to proj_dir. src_path is the resolved absolute path to the source file. issue is a non-empty string describing the developer intent. signals is a dict of pre-parsed signal dictionaries from _parse_issue_signals.
Post-condition: Returns a list of dicts, each with keys 'name' (function name string), 'score' (float relevance score), 'lineno' and 'end_lineno' (int line boundaries), sorted by descending score. Returns an empty list when the source file contains no localizable functions or when parsing fails. Ranking combines heuristic signal matching (traceback patterns, identifier references, exception-type presence) with call-graph score propagation where callees inherit a fraction of caller scores and vice versa.
