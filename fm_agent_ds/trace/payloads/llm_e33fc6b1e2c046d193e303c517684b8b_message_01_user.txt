Post-condition: Returns the fully-qualified name (FQN) string derived from filepath relative to proj_dir, with directory separators replaced by '::' and unsafe characters removed.

Pre-condition: file_paths is a list of (absolute_path, module_name) pairs for extracted function files. proj_dir is an existing directory. global_stem_to_fqns maps function-name stems to sets of FQN strings. extra_call_edges, when provided, is an iterable of supplemental edge records.
Post-condition: Returns a tuple whose elements include: callees_map (dict mapping caller FQN to list of callee FQN strings, sorted and deduplicated), callers_map (dict mapping callee FQN to list of caller FQN strings), all_callees_map (dict mapping FQN to list of all callee FQNs), file_map (dict mapping FQN to corresponding absolute file path), and module_map (dict mapping FQN to module name).
