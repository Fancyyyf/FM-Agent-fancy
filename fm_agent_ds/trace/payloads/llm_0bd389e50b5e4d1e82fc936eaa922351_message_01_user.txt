_parse_file(src_path: Path, proj_dir: str | None) -> tuple[list[dict] | None, list[str] | None, list[dict] | None]
Pre-condition: src_path is an absolute path to an existing source file. proj_dir, when provided, is the project root directory enabling non-Python parse paths to resolve function boundaries via codegraph.
Post-condition: Returns a tuple (funcs_info, source_lines, classes). funcs_info is a list of function-metadata dicts each containing keys for function name, start line, and end line, or None when no functions are found or parsing fails. source_lines is the file content as a list of strings (one per line), or None when reading fails. classes is a list of class-metadata dicts each with a 'name' key, or None when no classes are found.

_rank_functions(funcs_info: list[dict], classes: list[dict], signals: dict[str, set[str]]) -> list[dict]
Pre-condition: funcs_info is a non-empty list of function-metadata dicts from _parse_file. classes is a list of class-metadata dicts (possibly empty). signals is a dict of pre-parsed signal dictionaries from _parse_issue_signals with keys 'traceback_funcs', 'backtick_idents', 'dotted_refs', 'dotted_classes', 'plain_idents', 'exception_types', 'all_words'.
Post-condition: Returns funcs_info augmented with a 'score' key (float) on each entry, sorted by descending score. Scoring applies weighted signal matching: traceback-pattern overlap, backtick-identifier matches in function name and body, dotted-reference overlap, plain-identifier overlap in name, exception-type presence in the function body, and body-word overlap with intent tokens. When classes is non-empty, class-level scoring further boosts member function scores based on class-name and docstring overlap with the intent tokens.
