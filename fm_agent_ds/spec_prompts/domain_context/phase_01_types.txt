# Phase 01 — Initialization & Configuration

## Core Types

### `Settings` (Pydantic BaseSettings)
Central validated configuration object. Imported as `settings` module global.
```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(extra="forbid")
    llm: LLMCfg
    runtime: RuntimeCfg
    scope: ScopeCfg
    erlang: ErlangCfg
    inject: InjectCfg
    codegraph: CodegraphCfg
```
- Precedence: init_settings > (process env > .env > fm-agent.toml > built-in defaults)
- All sections use `extra="forbid"` — typo'd TOML keys or env vars fail fast at startup
- `_LayeredSource`: custom Pydantic source merging TOML + mapped env variables

### `LLMCfg` (Pydantic BaseModel)
```python
class LLMCfg(_Section):
    api_key: str = ""           # secret — from .env/env only, never committed
    base_url: str = "https://openrouter.ai/api/v1"
    backend: str = "opencode"   # "opencode" | "auto" | "codex-cli" | "claude-cli"
    name: str = "anthropic/claude-sonnet-4.6"
    effort: str = ""            # "" | "low" | "medium" | "high"
    provider: str = "openrouter"
    api_style: Literal["openai", "anthropic"] = "openai"
```

### `RuntimeCfg` (Pydantic BaseModel)
```python
class RuntimeCfg(_Section):
    max_spec_iter: int = 5         # gt=0
    granularity: int = 40          # gt=0 — lines per reasoning block
    max_workers: int = 10          # gt=0
    opencode_max_retries: int = 5  # gt=0
    bug_validation_max_retries: int = 1  # ge=0
    opencode_timeout_s: int = 1800 # gt=0 — hard cap on subprocess
    domain_knowledge_paths: str = ""  # os.pathsep-separated markdown paths
```

### `ScopeCfg` (Pydantic BaseModel)
```python
class ScopeCfg(_Section):
    top_k: int = 5                       # gt=0 — max functions per scoped file
    llm_trigger_funcs: int = 5           # gt=0 — file has ≥ this many funcs → LLM re-rank
    llm_top_k: int = 5                   # gt=0 — candidate functions requested from LLM
    llm_confidence_threshold: float = 8.0 # ge=0 — heuristic score below → LLM re-rank
```

### `ErlangCfg` (Pydantic BaseModel)

```python
class ErlangCfg(_Section):
```

```python
class InjectCfg(_Section):
```

## LLM Configuration Wizard Types

### `LLMConfigInput` (frozen dataclass)

## Environment Check Types

### `env_check.run(proj_dir, config) → bool`
Runs pre-flight checks. Returns True to proceed, False to abort.
Checks performed (when not using CLI backend):
- LLM API key configured (not empty/placeholder)
- oh-my-openagent installed via bunx
- comment-checker hook disabled in oh-my-openagent config
- codegraph pinned build matches version in fm-agent.toml

Ignored checks are persisted to `fm_agent/.env_check_memory` (one check-id per line).

## Git Utility Types

### `_is_git_repo(proj_dir) → bool`
Returns whether proj_dir is a git repo with at least one commit.

### `_get_head_commit(proj_dir) → str | None`
Returns HEAD commit SHA, or None if not a git repo.

### `_record_version(commit_id, work_dir) → None`
Appends commit_id to `fm_agent/version.log` for incremental run tracking.

### `frozen_worktree(proj_dir, exclude=("fm_agent",), copy_excluded=True) → context manager`
Yields an isolated git worktree snapshot. The snapshot includes committed state
PLUS uncommitted edits. `exclude` dirs are kept out of the git commit but
optionally copied in afterward. Falls back to plain directory copy for non-git repos.

## Entry Point Function Signatures

```python
def run(proj_dir, config) -> bool:
    """Run all env checks. Returns True to proceed, False to abort."""
```
